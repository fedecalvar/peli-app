# 🔍 ¿Qué se mira?

Buscador de películas construido con React y Vite, conectado a la API de TMDB.

## Tecnologías

- React
- Vite
- CSS
- TMDB API

## Instalación

1. Cloná el repositorio
2. Instalá las dependencias con `npm install`
3. Creá un archivo `.env` con tu API key de TMDB:

VITE_TMDB_API_KEY=tu_api_key

4. Ejecutá el proyecto con `npm run dev`

## Funcionalidades

- Búsqueda de películas en tiempo real
- Muestra póster, título, año y puntuación
- Diseño responsivo
- Resultados en español
